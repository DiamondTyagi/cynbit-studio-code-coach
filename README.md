# Cynbit Studio Code Coach

Submission for the **AI/ML Engineer Intern** task: *Identify an AI Opportunity for Cynbit*.
Author: Diamond Tyagi

## The idea in one paragraph

Cynbit Studio's public page promises AI coding missions, AI code evaluation and AI mentor support.
This project is a small proof of concept for that feature. A learner writes Python code for a mission, and the app:

1. checks the syntax,
2. looks at the code structure (for example a loop inside a loop, or `print` instead of `return`),
3. runs the code against test cases in a separate process with a time limit,
4. gives graduated hints (vague first, specific later),
5. uses a small ML model (decision tree) to estimate whether the learner is struggling and suggests an easier or harder mission.

The tests decide pass or fail. This keeps feedback fast, consistent and free of API cost.
An LLM would only be added later to explain *why* a test failed (see the technical report).

## Project structure

```

├── app.py                 # Streamlit screen the learner sees
├── src/
│   ├── missions.py        # the 4 practice problems, their tests and hints
│   ├── evaluator.py       # syntax check, structure check, test runner
│   └── ml_model.py        # decision tree: "does this learner need help?"

```

## How to run (Python 3.10 or newer)

```bash
git clone https://github.com/DiamondTyagi/cynbit-studio-code-coach.git
cd cynbit-studio-code-coach

python -m venv venv
# Windows:  venv\Scripts\activate
# Mac/Linux: source venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

The app opens at http://localhost:8501. No API key is needed, everything runs locally.

To run the automated tests:

```bash
pytest
```

To see the ML model's rules printed in the terminal:

```bash
python -m src.ml_model
```

## Things to know (honest limitations)

- **The ML model is trained on sample data**, generated by simple rules plus random noise, because Cynbit Studio's real learner data is not public. It shows the pipeline (features, train, test, predict). In production only the data source changes.
- **Running student code is only safe enough for a demo.** A real deployment must run it in a sandbox (for example a Docker container without network access).
- Test cases cannot judge code style or readability. That is where a reviewer or an LLM comment could help later.
- I only used public information about Cynbit. I do not know how Cynbit Studio evaluates code today, so this is a proposal that complements it, not a claim about what is wrong with it.
